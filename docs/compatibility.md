# 设备兼容表

唯一数据来源：`devices/*.json`。等级说明：

- **A** = 本项目实机读数验证
- **B** = 实机验证，但覆盖条件有限
- **C** = 协议已接入，待实机验证
- **D** = 已发现但未取得读数，不宣称兼容
- **E** = 已排除

等级只说明证据范围，不代表同品牌全系列可用。同一 VID:PID 可能被多家厂商的接收器复用，
本项目按 VID/PID + UsagePage/Usage + 产品名三重精确匹配，身份不符时不发送任何厂商查询命令。

| 设备 | 类型 | VID:PID | 集合 | 协议 | 等级 | 边界与证据 |

| 凌豹 K98 无线键盘 | keyboard | 0x3554 / 0xFA09 | 0xFF02:0x0002 | compx | A | 本机多次实机读数校验（2026-10-29 84%、11-01 43%、11-02 28%），FF02:0002 集合精确命中。注意 3554:FA09 被多家厂商接收器复用，且同一接收器另有 FF04:0002 集合，勿放宽匹配。 |
| 迈从 G3 V2 无线鼠标 | mouse | 0x3837 / 0x4245, 0x100A, 0x4018 | 0xFF01:0x0010 | yjx | A | 本机多次实机读数校验（62%、44%、25%），FF01:0010 集合精确命中；MCHOSE HUB 运行中亦可直读。同 VID 下 600A 为耳机、100C 为 A5 系列，协议不同，勿按 VID 泛化。 |

添加新设备：`cp devices/template.json devices/<型号>.json`，填好后运行
`python scripts/validate_devices.py --write-docs` 校验并刷新本表。
